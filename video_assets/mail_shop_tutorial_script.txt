MAIL-SHOP 5-MINUTE CARTOON TUTORIAL
Bangla narration with English product terms

CHAPTER 1 — Welcome and the big picture
স্বাগতম Mail-Shop-এর পাঁচ মিনিটের এই quick tutorial-এ। আজ আমরা একসঙ্গে শিখব কীভাবে একটি mailbox connect করবেন, Inbox refresh করবেন, গুরুত্বপূর্ণ message খুঁজে বের করবেন, এবং OTP Vault থেকে verification code copy করবেন। Mail-Shop হলো একটি focused email and OTP workspace—যেখানে অনেকগুলো account-এর message একটি পরিষ্কার dashboard-এ দেখা যায়। এই ভিডিওতে আমরা sample screen ধরে এগোব, তাই আপনার real account-এর password, token, বা OTP কখনোই কারও সঙ্গে share করবেন না। প্রথমবার খুললে চারটি প্রধান area দেখবেন: Inbox, OTP Vault, Accounts, এবং Settings। Inbox আপনার messages-এর home। OTP Vault কেবল real message বা documented API থেকে পাওয়া code সাজিয়ে দেখায়। Accounts-এ mailbox connection যোগ বা সরানো হয়। আর Settings-এ privacy, refresh, এবং display preference নিয়ন্ত্রণ করা যায়। চলুন শুরু করি Accounts দিয়ে, কারণ connected mailbox ছাড়া Inbox-এ নতুন message আসবে না।

CHAPTER 2 — Connect an account safely
প্রথমে Accounts tab খুলুন। এখানে আপনি DONGVANFB API-এর OAuth2 helper অথবা Microsoft Graph connection-এর মতো আপনার setup-এর উপযোগী method দেখতে পাবেন। যে form আপনার provider-এর জন্য প্রযোজ্য, সেটিই ব্যবহার করুন। Email, refresh token, client id, অথবা API key চাইলে তা শুধু নিজের trusted environment-এ বসাবেন; chat, screenshot, বা অন্য কারও form-এ পাঠাবেন না। চাইলে Label ঘরে সহজ একটি নাম দিতে পারেন, যেমন Work inbox বা Test account। সব তথ্য ঠিক থাকলে Add account চাপুন। নতুন account list-এ দেখা যাবে এবং status pill থেকে connected, syncing, বা error অবস্থা বোঝা যাবে। এরপর Sync বা Refresh action চালান। প্রথম sync-এ কিছুটা সময় লাগতে পারে, কারণ service নতুন message আনছে এবং OTP pattern পরীক্ষা করছে। কোনো error হলে একই token বারবার paste করবেন না। Error message পড়ুন, provider-এর permission এবং client id যাচাই করুন, তারপর আবার চেষ্টা করুন। কাজ শেষ হলে Accounts page-এ আপনার connected mailbox, last sync time, message count, এবং প্রয়োজন হলে Get code action দেখতে পাবেন। ব্যবহার শেষ হলে অপ্রয়োজনীয় account remove করে রাখাই ভালো।

CHAPTER 3 — Use Inbox like a control room
এখন Inbox tab-এ যাই। উপরের summary cards-এ Total emails, Unread, OTP detected, এবং Connected-এর count দেখা যায়। এগুলো live data-এর ছোট summary; code তৈরি করে না। নতুন message আনতে Refresh চাপুন। Inbox toolbar-এর search box-এ sender, subject, body, অথবা code লিখে দ্রুত খুঁজতে পারবেন। Account filter দিয়ে একটি নির্দিষ্ট mailbox বেছে নিন, আর Unread only চালু করলে শুধু না-পড়া message থাকবে। কোনো row খুললে sender, recipient, date, subject, read state, এবং message body দেখা যায়। ছোট screen-এ list view থেকে detail view-এ যেতে back button ব্যবহার করুন। Message দরকার হলে Copy message চাপুন। HTML email দেখতে ভালো লাগতে পারে, কিন্তু remote image tracking-এর ঝুঁকি থাকে; তাই অচেনা mail-এর image সবসময় সাবধানে দেখবেন। Graph message-এ server read state থাকতে পারে, কিন্তু কিছু provider-এ read state দেওয়া নাও থাকতে পারে—তাই interface যে status দেখায় সেটিই ধরুন। Mail-Shop শুধু API থেকে আসা real data দেখায়; empty Inbox মানে সাধারণত connection, permission, filter, বা refresh-এর বিষয়টি পরীক্ষা করা দরকার।

CHAPTER 4 — Find and copy an OTP
এবার OTP Vault। এই screen-এ real message content বা documented API field থেকে পাওয়া verification code আলাদা card-এ দেখা যায়। Mail-Shop নিজে কোনো code বানায় না, অনুমানও করে না। তাই code না এলে অপেক্ষা না করে প্রথমে Inbox refresh করুন এবং sender বা service name দিয়ে search করুন। Accounts থেকে account select করে service type বেছে নিন, তারপর Get code চাপুন। API response এলে code, source account, time, এবং subject-এর মতো context দেখা যাবে। কোনো card-এ Copy OTP চাপলে code clipboard-এ চলে যায়; এরপর যে sign-in page-এ দরকার সেখানে paste করুন। OTP খুব sensitive—এটি কাউকে forward করবেন না, public note-এ রাখবেন না, এবং অচেনা page-এ paste করবেন না। Code expired হলে নতুন message আসা পর্যন্ত অপেক্ষা করে আবার Refresh করুন। একই code একাধিক card-এ দেখা গেলে timestamp এবং source মিলিয়ে সবচেয়ে সাম্প্রতিকটি ব্যবহার করুন। Security-এর জন্য কাজ শেষ হলে clipboard clear করা ভালো। মনে রাখবেন, Mail-Shop-এর OTP Vault convenience layer; আসল authority সবসময় আপনার email provider বা service-এর message।

CHAPTER 5 — Settings, privacy, and final checklist
সবশেষে Settings tab একবার দেখে নিন। এখানে API key, proxy origin, Microsoft Graph client id, tenant, permission scope, এবং session preference-এর মতো configuration থাকে। এগুলো পরিবর্তন করার আগে provider documentation মিলিয়ে নিন। Auto-refresh Off রাখতে পারেন, অথবা thirty seconds থেকে five minutes-এর interval বেছে নিতে পারেন। List density এবং preview lines বদলালে Inbox আপনার screen অনুযায়ী আরামদায়ক হবে। Remote HTML-email images default-এ বন্ধ রাখাই privacy-friendly, কারণ image tracking pixel থাকতে পারে। Remember option চালু করলে এই tab-এর session storage-এ configuration থাকতে পারে—shared computer হলে এটি বন্ধ রাখুন। কাজ শেষ হলে account list review করুন, ভুল বা পুরোনো connection remove করুন, এবং browser বা device কাউকে দিলে session clear করুন। আজকের পুরো flow একবার মনে রাখি: Accounts-এ নিরাপদে connection যোগ করুন, Inbox-এ Refresh ও Search ব্যবহার করুন, message খুলে প্রয়োজনীয় তথ্য যাচাই করুন, OTP Vault থেকে real code copy করুন, আর Settings-এ privacy-first preference রাখুন। এই হলো Mail-Shop-এর quick workflow—simple, focused, এবং আপনার নিজের account data-এর নিয়ন্ত্রণ আপনার হাতেই। ধন্যবাদ, এবং নিরাপদে ব্যবহার করুন।
